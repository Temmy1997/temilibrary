# Virtuslization 
Virtulaization is the process of creating a vitual version of a physical resources (like server, desktop, operating system,storage, or netowkr resources) inside og using pysiscsl hardware direclty.

* Instead of buying 5 physical servers, you can use one powerful server and create 5 virtual servers on it — each acting like its own independent machine.

## VMWARE
* VMWARE is a company that provides virtualization and cloud infractructure software. 
* offer tools to manage and run virtual machines (VMs).

## Key VMware Product
1. VMware Workstation / Fusion
* For desktop/laptop use
* Lets you run multiple Operating systems  (like Linux, Windows, etc.) on your PC or Mac

2. VMware ESXi
* A bare-metal hypervisor
* Installs directly on physical hardware
* Used in enterprise environments to host virtual machines

3. VMware vSphere
* A suite of tools (includes ESXi + vCenter)
* Helps manage multiple VMs, automate tasks, and monitor performance

4. VMware vCenter
* A centralized management tool for managing multiple ESXi hosts and VMs
